# Европротокол+

«Европротокол+» — учебное веб-приложение для первичной регистрации дорожно-транспортных происшествий, ведения сведений об участниках и автомобилях, а также просмотра зафиксированных оповещений экстренных служб.

## Возможности

- журнал происшествий с поиском, фильтрами и постраничным выводом;
- создание и редактирование карточек ДТП с серверной проверкой данных;
- добавление водителя и автомобиля к карточке ДТП;
- отмена регистрации через защищённый POST-запрос без физического удаления записи;
- загрузка и просмотр фотоматериалов ДТП;
- сводные показатели по опасности происшествий, адресам и службам;
- административное управление объектами через `/admin/`;
- сохранённая консольная версия для просмотра учебных ДТП.

## Архитектура и база данных

Проект сохраняет исходную консольную версию ПР2–ПР3 (`main.py`, `models/`, `services.py`, `storage.py`) и Django-приложение (`europrotocol/`, `homepage/`, `accidents/`). Четыре таблицы, созданные на раннем этапе проекта, отображены моделями Django с `managed = False`: ORM использует текущую SQLite-базу и не пересоздаёт существующие таблицы. Фотографии размещены в отдельной мигрируемой модели `AccidentPhoto`.

| Модель | Таблица | Связи |
|---|---|---|
| `Accident` | `accidents` | имеет участников, оповещения и фотографии |
| `Participant` | `participants` | относится к ДТП и транспортному средству |
| `Vehicle` | `vehicles` | связан с участниками; госномер уникален |
| `EmergencyMessage` | `emergency_messages` | относится к ДТП |
| `AccidentPhoto` | `accidents_accidentphoto` | хранит путь к фото и описание, относится к ДТП |

Ручная схема и учебные SQL-запросы ПР7 сохранены в `sql/`. Веб-страницы получают данные через Django ORM. Для связей используются `select_related()` и `prefetch_related()`, статистика считается агрегатами ORM, список ДТП разбивается на страницы.

## Запуск

Требуется Python 3.11 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m db.import_json
python manage.py migrate
python manage.py check
python manage.py runserver
```

Импорт из JSON пересоздаёт записи в исходных таблицах, поэтому запускайте `python -m db.import_json` только при восстановлении учебного набора данных. Для доступа к административной панели создайте суперпользователя: `python manage.py createsuperuser`.

В режиме разработки изображения отдаются Django при `DJANGO_DEBUG=true`. Загруженные файлы сохраняются в `media/`, этот каталог не включается в Git. Перед запуском сервера с отладочным режимом не публикуйте его в открытом доступе.

## Маршруты

- `/` — сводные показатели и последние происшествия;
- `/accidents/` — журнал, фильтры и пагинация;
- `/accidents/create/` — регистрация происшествия;
- `/accidents/<id>/` — подробная карточка, участники и фотоматериалы;
- `/accidents/<id>/edit/` — изменение обстоятельств ДТП;
- `/accidents/<id>/participants/add/` — добавление участника и автомобиля;
- `/accidents/<id>/photos/add/` — загрузка фотоматериала;
- `/accidents/<id>/cancel/` — безопасная отмена регистрации методом POST;
- `/accidents/search/` — поиск по месту, категории и состоянию;
- `/accidents/participants/` — связанные данные участников и автомобилей;
- `/accidents/statistics/` — агрегированная статистика;
- `/admin/` — административная панель Django.
