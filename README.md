# Европротокол+

## Назначение

«Европротокол+» — программный продукт для автоматизации первичной регистрации дорожно-транспортных происшествий, сбора информации об аварии и определения необходимости оповещения экстренных служб.

Приложение должно упростить взаимодействие участников ДТП и сократить время передачи основной информации о происшествии.

## Целевая аудитория

Основными пользователями системы являются:

- водители — участники ДТП;
- сотрудники экстренных служб;
- сотрудники ГИБДД.

## Предметная область

Предметной областью проекта является автоматизация процессов оформления дорожно-транспортных происшествий, сбора информации от участников ДТП и передачи сведений экстренным службам.

## Основные сущности

- дорожно-транспортное происшествие;
- участник ДТП;
- транспортное средство;
- экстренная служба;
- сообщение о происшествии.

## Основные функции

- определение необходимости вызова экстренных служб;
- определение категории дорожно-транспортного происшествия;
- формирование информационного сообщения о ДТП.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
